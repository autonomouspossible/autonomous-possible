# Autonomous Possible

Process engineering company in Bangkok. We sell **engineering plus software** to process plants and factories.

**RIMX** is a lightweight **process historian** (real-time plant database). Connect DCS, PLC and SCADA over OPC UA, Modbus, MQTT and REST. Trends, KPIs and Python on the same history.

We do **not** replace the DCS. An LLM must **not** write DCS setpoints.
